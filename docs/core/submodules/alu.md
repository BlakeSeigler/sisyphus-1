## My ALU

* Ripple Over Adder (could have done a Carry Lookahead adder)

Operations:
0000 - Add
0001 - Subtract
0010 - AND
0011 - OR
0100 - XOR
0101 - SLT           // Set less than
0110 - SLL           // Shift Left   
0111 - SRL           // Shift Right      
1111 - SRA           // Shift Right Arithmetic
SLTU          // Set Less than unsigned

This is the RISC-V32 ISA commands
